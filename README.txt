# IPL Auction Game
1. Upload `index.html` to any static hosting service such as GitHub Pages, Netlify, or Vercel.
2. Open the hosted link.
3. Player 1 clicks Create Room.
4. Share the 6-character room code with Player 2.
5. Player 2 enters the code and clicks Join Room.
6. Host starts each player and controls SOLD/SKIP.
The game uses PeerJS for peer-to-peer browser communication; both players need internet access.
